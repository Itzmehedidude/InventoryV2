# StockFlow (InventoryV2)
Original StockFlow design + Supabase login, shared cloud inventory, realtime sync and offline queue.

Setup: run `supabase/schema.sql` in Supabase SQL Editor; set Site URL to your GitHub Pages URL; put URL + Publishable key in `config.js`; upload all files to the repo root.
Old offline backups can be imported from Settings → Import.
